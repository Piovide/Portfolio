Platformer

Map Builder

Applicazione sviluppata parallelamente al platformer per semplificare la creazione dei livelli di gioco. L’interfaccia è composta da una toolbar laterale e da una canvas centrale in cui disegnare la mappa. Sono presenti funzioni come:

  • salvataggio in bitmap,
  • gomma e cancella,
  • rotazione e variazioni dei tile premendo R.

Questo tool ha reso molto più veloce e intuitivo lo sviluppo delle mappe per il platform.

  • Data di inizio: Marzo 2024
  • Data di fine: Maggio 2024
  • Technologie utilizzate: Java
  • Collaboratori: Marco Furlan
  • Link al repository: GitHub

Wiki Appunti

Progetto nato come strumento personale per organizzare i miei appunti in vista dell’esame di stato, con l’idea di espanderlo in futuro per un utilizzo collaborativo tra studenti. Le funzionalità principali includono:

  • login e registrazione con verifica via email,
  • scrittura in Markdown con una toolbar che semplifica l’inserimento di elementi comuni (grassetto, corsivo, liste, titoli, code snippet).

Mi sono occupato soprattutto del frontend Flutter, in particolare dell’editor di scrittura, e della gestione del web service backend.

  • Data di inizio: Marzo 2025
  • Data di fine: Maggio 2025
  • Technologie utilizzate: Flutter, Dart, PHP
  • Collaboratori: Ceolin Giovanni, Marco Furlan
  • Link al repository: GitHub

Gestione Progetto

Un sito sviluppato per monitorare i progressi di un progetto di gruppo. Consente ai membri di aggiungere task con titolo, descrizione, data e durata in ore. Le funzionalità comprendono:

  • lista delle task condivisa,
  • grafico con il conteggio delle ore totali per ogni membro,
  • una sezione “Info” che integra Google API per visualizzare direttamente il WBS e il RACI da un foglio Excel di Google.

Pensato inizialmente per il mio team, con piccole modifiche potrebbe diventare uno strumento utile anche ad altri gruppi di lavoro.

  • Data di inizio: Novembre 2024
  • Data di fine: Giugno 2025
  • Technologie utilizzate: PHP, CSS, JS, MySQL, HTML
  • Link al repository: GitHub

Solariel

Un progetto di gruppo nato da una mia idea, ispirata allo stile solarpunk del video Dear Alice. L’obiettivo era realizzare un survival in prima persona ambientato in un mondo solarpunk, ma il progetto si è fermato a una alpha demo tecnica a causa dell’inesperienza del team con Unreal Engine.
Mi sono occupato della creazione della mappa di gioco, della UI dell’inventario, e della logica di interazione con gli oggetti e la hotbar. Nonostante le difficoltà, il progetto ha permesso di sperimentare e consolidare competenze nel game design con Unreal Engine.

  • Data di inizio: Gennaio 2025
  • Data di fine: Giugno 2025
  • Collaboratori: Aiello Eros, Bettello Nicholas, Ceolin Giovanni, Marco Furlan, Mestriner Paola
  • Technologie utilizzate: Unreal Engine, C++

Zenless Zone Zero Calculator

Un sito pensato per i giocatori di Zenless Zone Zero, con l’obiettivo di aiutare a ottimizzare la build dei propri personaggi. L’applicazione consente di:

  • selezionare diversi tipi di attacchi,
  • calcolare il danno prodotto,
  • trovare la combinazione migliore di artefatti e arma.

I dati dei personaggi vengono salvati in JSON nel local storage del browser, così da mantenere la configurazione anche nelle sessioni successive. Attualmente il progetto è in fase embrionale, ma l’obiettivo è renderlo uno strumento pratico e intuitivo per la community.

  • Data di inizio: Gennaio 2025
  • Data di fine: WIP
  • Collaboratori: Franceschet Tommaso
  • Technologie utilizzate: TypeScript, PHP, CSS
  • Link al repository: GitHub
